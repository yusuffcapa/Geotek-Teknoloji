# 🌍 GEOTEK Teknoloji

**GEOTEK Teknoloji** için geliştirilmiş bir kurumsal web sitesidir.  
Bu web sitesi, firmanın **otomatik presiyometre cihazını** tanıtmakta, yaptığı çalışmalar hakkında bilgiler sunmakta ve **galeri bölümü** ile projelerini ziyaretçilere göstermektedir.

---

## ✨ Özellikler

- 🧭 Şirket hakkında detaylı bilgi sayfaları  
- 🧰 Otomatik presiyometre cihazının tanıtımı  
- 🖼️ Görsel galeri bölümü  
- 📞 İletişim formu  
- 💬 Dinamik sayfa yapısı (PHP tabanlı)  

---

## 💻 Kullanılan Teknolojiler

| Teknoloji | Açıklama |
|------------|-----------|
| **HTML5** | Sayfa yapısı ve içerik düzeni |
| **CSS3** | Görsel tasarım ve responsive yapı |
| **JavaScript (Vanilla)** | Etkileşimli öğeler, animasyonlar |
| **PHP** | Dinamik içerik yönetimi, form işlemleri |
